AI速 プライバシーポリシー

「AI速」（以下「本アプリ」といいます）の運営者は、 本アプリにおける利用者情報の取扱いについて、 以下のとおりプライバシーポリシーを定めます。

1. 取得・利用する情報

本アプリでは、サービスの提供、品質改善、不正利用防止、 広告配信、利用状況の分析等のため、 以下の情報を取得または利用する場合があります。

広告に関する情報

本アプリでは、広告配信のためGoogle AdMobを利用します。

Google AdMobおよびGoogle Mobile Ads SDKにより、 広告配信、広告効果測定、不正利用防止等のため、 端末情報、広告関連情報、IPアドレス、 広告の表示や操作に関する情報等が取り扱われる場合があります。

また、必要な地域ではGoogle User Messaging Platform（UMP）を利用し、 広告等に関する利用者の同意情報を管理します。

アプリの利用状況に関する情報

本アプリでは、サービスの品質改善、 AI生成機能および広告表示の運用・分析等を目的として、 次のような技術情報を記録する場合があります。

  • 広告の読み込み、表示、インプレッションおよび収益に関する情報
  • AI生成処理の実行状況
  • AI生成に使用したモデルやトークン数等の技術情報
  • アプリ内機能の利用に関する技術情報
  • エラーその他の動作状況に関する情報

これらの情報は、サービスの運営、 品質改善、広告およびAI機能の費用・収益分析等のために利用します。

ユーザー投稿

本アプリでは、ニュースに対して利用者がコメントを投稿できる機能を提供します。

投稿内容は、コメントの表示、返信処理、 AIによる返信生成その他の本アプリの機能を提供するために 処理される場合があります。

投稿欄には、氏名、住所、電話番号、メールアドレス、 その他の個人情報や機密情報を記載しないようお願いいたします。

AI生成コンテンツの通報

本アプリでは、AIによって生成されたコメントを表示する場合があります。

利用者がAI生成コメントを通報した場合、 不適切なコンテンツへの対応およびサービス改善のため、 通報対象の情報、ニュースに関する情報、 通報理由、通報日時等を保存する場合があります。

2. 外部サービス

本アプリでは、機能提供のため、 以下を含む外部サービスを利用する場合があります。

  • Google AdMob / Google Mobile Ads SDK
  • Google User Messaging Platform（UMP）
  • Supabase
  • Upstash Redis
  • AI生成サービスおよび関連API
  • RSS配信元その他ニュース情報の取得に必要なサービス

これらの外部サービスへ、本アプリの機能提供に必要な範囲で 情報が送信される場合があります。

各外部サービスにおける情報の取扱いについては、 各サービス提供者が定めるプライバシーポリシー等が 適用される場合があります。

3. 広告および同意設定

本アプリではGoogle AdMobによる広告を表示します。

利用者の地域その他の条件に応じて、 広告のパーソナライズ等について 同意を求める画面が表示される場合があります。

対象となる場合、本アプリ内のプライバシー設定から、 広告等に関する同意内容を確認または変更できます。

4. 第三者への情報提供

本アプリの運営者は、法令に基づく場合を除き、 本ポリシーに記載した目的を超えて、 利用者情報を第三者へ提供しません。

ただし、本アプリの機能提供に必要な範囲で、 広告配信、データ保存、AI処理等を行う 外部サービスへ情報が送信される場合があります。

5. 情報の安全管理

本アプリの運営者は、取得した情報について、 不正アクセス、漏えい、改ざん、滅失等を防止するため、 合理的な安全管理措置を講じるよう努めます。

6. 情報の保持および削除

取得した情報は、サービス提供、品質改善、 不正利用防止、法令上の義務その他、 取得目的の達成に必要な期間保持する場合があります。

保持する必要がなくなった情報については、 合理的な期間内に削除または匿名化するよう努めます。

利用者から、運営者が保有する当該利用者に関する情報について 削除等の適法な請求があった場合は、 必要な確認を行ったうえで、 法令およびサービス運営上必要な範囲で対応します。

7. 未成年者の利用

未成年者が本アプリを利用する場合は、 必要に応じて保護者等の同意を得たうえで利用してください。

8. プライバシーポリシーの変更

本ポリシーは、法令、本アプリの機能、 利用する外部サービス等の変更に応じて 改定する場合があります。

重要な変更がある場合は、 本アプリ内その他適切な方法で周知します。
