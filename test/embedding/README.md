# AI速 Embedding比較用・架空データ v1

- 30記事 / 15の正解Topic / 30評価ペア（同一15、紛らわしい別9、無関係6）
- 全記事は架空です。実ニュースの精度を保証するものではありません。
- `articles.csv` の `embedding_input` 列だけを各モデルへ渡してください。
- `ground_truth_topic` と `evaluation_pairs.csv` は採点専用です。モデル入力には含めないでください。
- 比較時は各モデルの出力を同じモデル内でcosine比較してください。異なるモデル間でベクトルを直接比較しないでください。
- Top1検索は、各Topicの先頭記事（奇数ID）15件を登録し、残りの偶数ID15件を検索してください。
- Top1正解率と、hard_negativeを誤って上位に出す傾向を確認してください。
- 閾値0.88はGoogle現行値の参考値。BGE-M3へ流用せず別途調整してください。
- 30件は疎通・初期比較用です。本番移行判断には実ニュースでの追加検証が必要です。
